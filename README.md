# Conway's Game of Life

A C# console implementation of Conway's Game of Life, a cellular automaton devised by mathematician John Conway.

## Description

Conway's Game of Life is a zero-player game that evolves based on its initial state. The game takes place on a 2D grid of cells, where each cell can be either alive or dead. The state of the grid evolves over time according to simple rules based on the number of living neighbors each cell has.

## Features

- 2D grid-based board with customizable dimensions
- Visual representation of alive and dead cells in the console
- Board display with outlined borders
- Ability to clear the board state

## Technologies

- **Language:** C# 13.0
- **Framework:** .NET 9
